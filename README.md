# 🐾 GatilDeglis

Sistema web desenvolvido para gerenciamento de um gatil especializado nas raças **Ragdoll** e **American Curl**.

O projeto faz parte da disciplina **Software Product: Analysis, Specification, Project & Implementation** e está sendo desenvolvido utilizando metodologia ágil com organização em Sprints.

## 🚀 Tecnologias

- Angular
- TypeScript
- HTML
- CSS / SCSS
- Git
- GitHub

## 📂 Estrutura do Projeto

src/app

- models
